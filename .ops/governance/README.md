- **Proposito:** reglas de gobierno del ciclo de vida: quien decide, cuando algo esta listo y como se cambia el rumbo.
- **Escribe:** rol:agente (propone) / **Aprueba:** rol:propietario.
- **Cuando:** al abrir el proyecto (carta) y al detectar la necesidad de cambiar alcance, fases o procesos.

## Documentos (se crean segun necesidad)

- `roles-raci.md` - quien propone, aprueba y valida; define los roles usados en frontmatter.
- `definition-of-done.md` - DoR y DoD de tareas y fases.
- `change-control.md` - como se cambia el rulebook del proyecto, el alcance o las fases.
- `risks.md` - registro de RSK-NNN con senales de disparo.
